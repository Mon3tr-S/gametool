# ゲームアイデア生成ツール

AIがゲームのアイデアを10個提示し、カードをタップするとその場で**遊べるデモ（単一HTML）**が生成される。
気に入ったものは「作り込む」でより深い版に作り直し、手触りの違和感は「修正する」で安く直せる。
生成したゲームは保存され、APIを呼ばずに再訪できる。スマートフォンのブラウザでの利用を想定。

> 設計の前提：**AIは候補と実装を作る／人間は触って判断する。** AIに面白さを判定させる方向には進めない。

---

## 準備（初回のみ）

### 1. 依存を入れる

```
pip install -r requirements.txt
```

Pythonが無い場合は https://www.python.org からインストール（「Add Python to PATH」にチェック）。

### 2. APIキーを用意する（環境変数で渡す）

このリポジトリに**APIキーは含まれていません**。各自のキーを環境変数で渡してください。

| 環境変数 | 必須 | 用途 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ | ゲーム生成・作り込みなど（https://console.anthropic.com で取得。`sk-ant-` で始まる） |
| `GEMINI_API_KEY` | 任意 | アイデア出し等の軽い処理を安価に回す（https://aistudio.google.com/apikey）。未設定なら自動で Claude Sonnet にフォールバック |

**従量課金**が発生します（目安：アイデア10案 約$0.02／ゲーム1本 約$0.05〜0.1／作り込み1回 約$0.15〜0.5）。

## 起動

Windows なら `start.bat` をダブルクリック（APIキーの入力を求められる）。または直接：

```
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

ブラウザで `http://localhost:8000` を開く。

### スマホ・別端末から使う

PCと同じネットワークに繋ぎ、`ipconfig` で調べたPCのIP（`192.168.x.x` など）を使って
スマホのブラウザで `http://192.168.x.x:8000` を開く（繋がらない時はWindowsファイアウォールの受信許可を確認）。

## できること

- **アイデア生成**：テーマ（空欄可）から、掛け合わせ対象を軸にした10案。過去の回は履歴から再訪可能
- **ゲーム生成**：カードをタップで単一HTMLのデモを生成し、その場でプレイ
- **作り込む**：元アイデアの核心を保ったまま深い版に作り直す（モデルは Sonnet / Opus / Fable から選択、別版として保存）
- **修正する**：手触りの違和感を、数値調整（安い）か構造変更（確認あり）に自動で振り分けて修正。「元に戻す」あり
- **検証**：非表示で自動プレイして実行時エラーを検出し、AI修復まで（ブラウザ内で完結・追加費用なし）
- **言語チェック（LQA）**：多言語化したゲームで、枠に入りきらない表示崩れ（はみ出し・文字切れ）や未翻訳を、必要px/枠pxの実数で検出（ブラウザ内で完結・追加費用なし）

## 無料で動かす（任意・要 Claude Code）

環境変数 `USE_CLAUDE_CLI=1` を設定すると、すべてのAI呼び出しをローカルの
[Claude Code](https://claude.com/claude-code) CLI（定額プランの枠）経由にして、**API従量課金なし**で動かせます。
Claude Code がインストール＆ログイン済みであることが前提。未設定時は通常のAPIモードです。

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | サーバー本体（FastAPI）。用途別にモデルを使い分け、CLI/APIを切り替える |
| `static/index.html` | 画面。スマホ向け。生成・作り込み・修正・検証・言語チェックのUI |
| `start.bat` | Windows 起動用 |
| `saved/` | 生成されたゲームの保存先（実行時に作られる。リポジトリには含めない） |

モデルの割り当ては `app.py` 冒頭の `MODEL_*` 定数で変更できます。

---

## 注意

- **APIキーは環境変数で渡し、コミットしないこと**（`.env` 等は `.gitignore` 済み）
- 生成されるゲームは当たり外れがあり、動かないものが混ざることもある
- `saved/` の中身（生成物・履歴）はリポジトリに含めていません
